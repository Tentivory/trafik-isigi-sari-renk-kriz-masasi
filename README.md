# T.C. Trafik Isigi Sari Renk Kriz Masasi

> Sari yandi. Meclis toplandi. Kimse durmadi. Tutanak tutuldu.

Bu depo, sari isigin milli bir belirsizlik alani oldugu gerceginden hareketle kurulmus **resmi, ciddi ve tamamen gereksiz** bir kriz yonetim yazilimidir.

Kirmizi durur.  
Yesil gecer.  
Sari **evrak basar**.

## Neden vardir?

Cunku sari isik:
- ne tam duraktir,
- ne tam gecistir,
- tam olarak bir **tutanak firsatidir**.

Uluslararasi ISO-SARI-2026 standardina (bu sabah uydurulmustur) uygundur.

## Kurulum

```bash
python3 sari_kriz.py
python3 sari_kriz.py 06-KRIZ-42
```

Calisir. Isiniza yaramaz. Gururumuzdur.

## Resmi iddialar

1. Sari isigin suresi anayasal 3 saniyedir; sahada sonsuzdur.
2. Yaya butonu kriz masasinin cekimser uyesidir.
3. Sol seritteki taksi gozlemci statundedir, oy kullanamaz, korna calabilir.
4. Bu yazilim kimseyi gecirmez, kimseyi durdurmaz, sadece **karar yayimlar**.

## Sorumluluk reddi

Bu yazilim trafik kazasi, gec kalma, evlilik krizi veya koalisyon gorusmesi icin kullanilamaz.  
Kullanilirsa tutanak yine de uretilir.
